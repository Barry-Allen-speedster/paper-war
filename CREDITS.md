# Credits

## Audio

All sounds in Paper War are procedurally generated at runtime using the Web Audio API.
No external audio files are loaded or bundled.

Sound design based on Web Audio oscillators and envelope shaping.
No third-party audio assets are used.

## Fonts

The following Google Fonts are referenced in theme configurations.
They are loaded via `next/font` (self-hosted at build time, no runtime Google requests):

- **Caveat** — Notebook Sketch theme (handwritten style)
  Designed by Impallari Type. SIL Open Font License 1.1.

- **Share Tech Mono** — Neon Blueprint theme (monospace terminal)
  Designed by Carrois Apostrophe. SIL Open Font License 1.1.

- **IM Fell English** — Vintage Parchment theme (old-style serif)
  Designed by Igino Marini. SIL Open Font License 1.1.
